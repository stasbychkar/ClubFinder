# 🎯 ClubFinder

**ClubFinder** is an interactive web application that helps students find campus clubs aligned with their academic interests, career goals, and personal passions. Through a brief quiz, students receive a personalized list of clubs.

## 🌟 Features

- ✅ Quick, user-friendly quiz to identify student interests
- ✅ Tailored club recommendations based on quiz responses

## 🔧 Technologies Used

- HTML, CSS, JavaScript  
- Firebase, Firestore
